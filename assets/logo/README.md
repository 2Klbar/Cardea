# Cardea logo — "keyhole arch"

A Roman arch with a keyhole, on a threshold: Cardea is the goddess of door hinges and thresholds. Colour: verdigris,
the patina of bronze hinges.

| File | Use |
|---|---|
| `cardea-light.svg` | Logo on light backgrounds |
| `cardea-dark.svg` | Logo on dark backgrounds |
| `cardea-app.svg` | App icon (menus, window list): dark tile, readable on light and dark |
| `tray/cardea-tray-<state>-<theme>.svg` | Tray icon. States: `idle` (no sandbox running, outlined and dimmed), `running` (green ✓ badge), `busy` (blue turning-arrow badge), `error` (red ! badge). Theme = panel background. |
| `preview.html`, `preview.png` | Everything side by side |
| `gen_logo.py` | **Source of truth**: edit it, then run `python3 gen_logo.py` |
